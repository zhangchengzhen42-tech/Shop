## 覆盖的关键场景

- 20 路并发抢购只创建 5 单，库存不超卖。
- 取消/超时关闭仅释放一次库存。
- 重复支付、重复退款通知保持幂等；渠道交易号不能跨订单复用。
- 迟到支付进入异常退款且不重新占库存。
- 退款申请和发货竞争只产生一个合法结果；退款拒绝后可发货。
- 渠道退款失败可重试，成功后正常退款仅恢复一次库存。
- 签名 Cookie、未登录跳转、篡改会话、POST-only 和角色越权处理均有 HTTP 测试。
- 审计写入失败及查询数据损坏会返回错误并回滚事务，不产生部分提交。

## 结论

本地格式、静态分析、测试及覆盖率门禁通过。由于本机没有 gcc，`go test -race ./...` 未执行成功，因此不能标记为最终发布验收通过；需要在具备 CGO/C 编译器的环境补跑 race，并在获得权限后补齐远程 CI、部署和演示证据。
