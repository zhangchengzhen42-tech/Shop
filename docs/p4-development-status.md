# P4 开发状态

## 已完成

- Go + SQLite 持久化核心业务。
- 订单创建时按条件原子占用库存，订单保留商品和价格快照。
- 10 分钟待付款关闭，重复关闭不重复释放库存。
- 支付验签、金额匹配、渠道交易号唯一、重复通知幂等。
- 关闭后的迟到支付进入异常，不恢复订单或库存。
- 退款申请期间暂停发货，客服审批，渠道失败可重试，正常退款只恢复一次库存。
- 退款与发货通过条件更新竞争，只有一个合法结果成功。
- 运营维护商品价格、库存和上下架，历史订单快照不变。
- 买家、仓库、客服、运营、支付渠道页面及角色签名 Cookie。
