# 交易一致性检查结果

范围：`internal/app/service_test.go`、`internal/web/server_test.go` 及 P5 期间调整的启动代码。
规则覆盖：库存占用与释放、支付和退款幂等、迟到支付、退款/发货互斥、角色权限、审计失败回滚。

## 发现

- 无新的高风险业务缺陷。
- [环境] `go test -race ./...` 不能启动；已确认原因是 `CGO_ENABLED=1` 后系统找不到 gcc，而非测试失败。

## 已验证

- 并发下单、退款/发货竞争、重复渠道通知均有自动测试。
- 支付、退款、发货等事务在审计写入失败时返回错误并回滚。
- 关闭订单后的迟到支付仅产生异常处理记录，迟到退款不恢复库存。
- HTTP 层拒绝未登录、篡改会话、GET 状态变更和买家越权商品维护。

## 未覆盖或需人工确认

- 未在有 gcc 的环境运行 race。
- 未验证多进程/多实例 SQLite 锁竞争、远程 CI/CD 与生产部署。

结论：有条件通过。业务状态与测试证据满足本地门禁；race 与外部过程门禁待具备环境后补齐。
